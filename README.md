# Casas Promoción · Altavista Residencias (prototipo)

Sitio para venta de 4 casas (3 Puerto Vallarta, 1 Puebla). React + Vite + Tailwind v4.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # producción en dist/
```

Documentación de rutas, componentes y datos: [CLAUDE.md](./CLAUDE.md) (copia en `docs/MEMORIA.md`).
Los datos de las casas viven en `src/data/casas.ts` (todo placeholder).
